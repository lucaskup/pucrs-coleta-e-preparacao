Coleta e Preparação de Dados PUCRS Online · Prof. Lucas Kupssinskü

Arquivos de dados, páginas para scraping e notebooks usados nos exercícios da disciplina. Todo o material é sintético e autocontido: pode ser lido direto destas URLs ou baixado de uma vez.

Aulas

Aula 1

Arquivos de texto, CSV, XML e JSON

Codificação de caracteres, open, read_csv, read_xml, read_json e normalização.

  • Página estática de corpo docente: alvo do exercício de wget + grep
  • Índice dos arquivos: txt, csv, xml e json, com o que cada um exercita
Descrição dos arquivos e comandos da aula
Aula 2

Expressões regulares e APIs REST

Regex para extrair informação de texto; coleta em APIs REST com requests, paginação e proveniência.

  • Testador de expressões regulares: escreva a regex e veja os casamentos destacados
  • mbox-short.txt e os três exercícios de regex dos slides
  • API estática: 497 municípios do IBGE, paginados, para praticar requests
Descrição dos arquivos e comandos da aula
Aula 3

Web scraping

HTTP, HTML e DOM; seletores CSS; XPath; BeautifulSoup; robots.txt e sitemap.

  • Livraria Aurora: 24 livros em 3 páginas, com paginação e páginas de detalhe
  • Países: alvo dos exemplos de XPath
  • Painel dinâmico: conteúdo montado por JavaScript
  • Índice completo das páginas da aula
Descrição das páginas e comandos da aula
Aula 4

KDD, tipos de dados e estatística descritiva

Níveis de medição, medidas de localização, dispersão, forma e associação; roteiro de EDA.

  • imoveis_aurora.csv: base de anúncios fictícios com problemas plantados
Descrição dos arquivos da aula
Aula 5

Visualização, similaridade e pré-processamento

Escolha e integridade de gráficos; Minkowski, cosseno, SMC, Jaccard, Gower.

  • imoveis_aurora.csv: a mesma base da aula 4
Descrição dos arquivos da aula
Aula 6

Limpeza, integração, redução e transformação

Ausentes, outliers, integração de duas fontes, normalização, discretização e PCA.

  • Índice dos arquivos: base de imóveis, anúncios em JSON e tabela de bairros para integrar
